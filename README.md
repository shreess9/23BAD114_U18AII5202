📌 Overview

This repository contains all 7 laboratory exercises for the course Exploratory Data Analysis and Visualization (EDA).

The experiments focus on:

Understanding data types and levels of measurement

Data cleaning and preprocessing

Visualization principles

Statistical measures

Time-series analysis

Ranking and deviation analysis

R programming implementation

All programs are implemented using R Programming and relevant visualization libraries.

🧪 Exercise 1 – Introduction to Data & Visualization Basics
🎯 Objective

To understand:

Types of data (Categorical, Continuous)

Levels of measurement (Nominal, Ordinal, Interval, Ratio)

Importance of visualization

📚 Concepts Covered

Human visual perception

Improper encoding effects

Visual variables (color, size, shape, position)

🛠 Tools Used

R Programming

Base R plotting functions

📊 Outcome

Learned how improper visualization can mislead interpretation and how correct encoding improves analytical clarity.

🧪 Exercise 2 – Data Cleaning & Preprocessing
🎯 Objective

To clean raw datasets and prepare them for analysis.

📚 Concepts Covered

Handling missing values

Removing duplicates

Data transformation

Data formatting

Outlier detection

🛠 Tools Used

R

dplyr package

📊 Outcome

Understood the importance of preprocessing before performing statistical analysis.

🧪 Exercise 3 – Measures of Central Tendency & Dispersion
🎯 Objective

To compute statistical measures.

📚 Concepts Covered

Mean

Median

Mode

Variance

Standard Deviation

Range

Coefficient of Range

🛠 Formulas Used
Mean = ΣX / n

Variance = Σ(X - X̄)² / (n - 1)

Standard Deviation = √Variance

📊 Outcome

Understood variability and distribution spread in datasets.

🧪 Exercise 4 – Data Visualization Techniques
🎯 Objective

To create effective visual representations of data.

📚 Visualizations Implemented

Bar Chart

Pie Chart

Histogram

Box Plot

Scatter Plot

🛠 Libraries Used

ggplot2

Base R graphics

📊 Outcome

Learned how different charts are used for categorical and continuous data representation.

🧪 Exercise 5 – Time-Series Analysis
🎯 Objective

To analyze time-dependent data.

📚 Concepts Covered

Trend Component (Tₜ)

Seasonal Component (Sₜ)

Cyclical Component

Irregular Component

Additive Model

Multiplicative Model

📈 Time-Series Models

Additive Model:

Yₜ = Tₜ + Sₜ + Cₜ + Iₜ


Multiplicative Model:

Yₜ = Tₜ × Sₜ × Cₜ × Iₜ

📊 Outcome

Understood decomposition of time-series data and interpretation of trends and seasonal variations.

🧪 Exercise 6 – Ranking Analysis
🎯 Objective

To rank data and compare performance.

📚 Concepts Covered

Ranking methods

Percentile ranking

Comparative performance evaluation

📊 Outcome

Learned to identify top performers and evaluate relative standing within datasets.

🧪 Exercise 7 – Deviation Analysis
🎯 Objective

To measure deviation between actual and target values.

📚 Concepts Covered

Absolute Deviation

Percentage Deviation

Positive and Negative Deviation

Performance Analysis

📈 Formulas Used
Absolute Deviation = Actual − Target

Percentage Deviation =
((Actual − Target) / Target) × 100

📊 Outcome

Understood how deviation analysis supports business performance evaluation and decision-making.
